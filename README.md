# skills

Agent skills. Each folder holds one skill as a `SKILL.md` with its frontmatter, in the format Claude Code and Codex load.

| Skill | What it covers |
| --- | --- |
| [`feedback-loops`](feedback-loops/SKILL.md) | Defects crash loudly where they are detected; only expected failures get a bounded, visible retry or fallback. |

To use one, copy its folder into `~/.claude/skills/` (or a project's `.claude/skills/`).
